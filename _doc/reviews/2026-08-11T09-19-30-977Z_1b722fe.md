### web/routes/_middleware.ts
- `getStreetHousesStatus` ajoute une requête (séquentielle après `findSessionUserById`) sur **chaque** requête authentifiée, y compris les POST qui ne rendent pas le Header (`/taps`, `/deconnexion`...). Acceptable, mais si la charge le justifie, une seule requête jointe (user + statut rue) ou un cache en session ferait l'économie d'un aller-retour.

### web/components/Header.tsx
- `isStreetAwake` optionnel avec masquage par défaut : tout point d'appel oublié (typiquement `/connexion` ou `/rejoindre` si elles affichent le Header à un utilisateur connecté) cachera silencieusement les liens même pour une rue allumée. Rendre la prop obligatoire forcerait chaque appelant à trancher explicitement.

- Nit de nommage : `const { unit, ms } = UNITS.find(({ ms }) => absMs >= ms)!` — le `ms` du prédicat et le `ms` déstructuré se télescopent ; renommer le paramètre du prédicat (`threshold` ?) lèverait l'ambiguïté. La logique du `find(...)!` est sinon correcte (la garde des 60 s garantit un match).
